# 🔄 Bubble Sort in Java

A simple implementation of the **Bubble Sort algorithm using Java**.

This project demonstrates how Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

---

## 📌 About the Project

Bubble Sort is a simple sorting algorithm that works by repeatedly comparing adjacent elements in an array.

If the elements are in the wrong order, they are swapped.

After each pass, the largest unsorted element moves to its correct position at the end of the array.

## 🚀 Features

- Sorts an array of integers in ascending order
- Takes input from the user
- Uses nested loops for sorting
- Demonstrates the swapping technique
- Beginner-friendly Java implementation
